## Install

1. Open `/xlsettings` in game.
2. Open **Experimental** → **Custom Plugin Repositories**.
3. Add and enable this URL:

   https://raw.githubusercontent.com/wallawallaslytherin/dalamud-plugins/main/pluginmaster.json

4. Open `/xlplugins` to install or update a plugin.
