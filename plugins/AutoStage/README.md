# AutoStage

Authenticate your character in PlayerSync or Lightless first. If both are authenticated, AutoStage prefers PlayerSync.

Enter a configured estate to join its syncshell, subscribe to its venue layout and load its active stages automatically. AutoStage installs Stagehand for PlayerSync or Intoner for Lightless if needed. It keeps one selected route during your visit and temporarily suspends the other estate renderer to prevent duplicate stages. Your character-mod synchronization stays available. On exit, it restores only the renderer that was previously active. Existing disabled plugins, paused syncshells, unrelated subscriptions and media preferences remain unchanged.

Use `/autostage` to view status. After updating, use `/autostage retry` to retry a failed setup.

New Lightless guest onboarding has not yet been verified in game.

Automatic installation of a missing renderer has not yet been verified in game.
