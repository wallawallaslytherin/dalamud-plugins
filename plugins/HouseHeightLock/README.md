# Z-Lock

Inside a player house, open `/zlock`, choose a 1–10 cm **Lift**, and press **Lock Height & Movement**. Press **Unlock** to return to normal movement.

Optional controls:
- **Allow movement** lets you move horizontally while height stays locked. Unlock before changing this option.
- **Disable when another player is present** prevents locking or unlocks when another player is detected in the house.
- **Auto-enable in housing placement mode** locks when you enter housing placement mode and releases that automatic lock when you leave it.

Closing the window leaves the lock active. Use **Unlock** to release it.
