# Gearset Organizer

Open `/gearsets`, review the current and proposed gearset numbers, then press **Sort gearsets** to arrange them by role and job.

After changing gearsets, equipment, hotbars or macros, press **Refresh preview** before sorting. Resolve any blocker shown in the window.

Use **Undo last sort** to restore the latest ordering while it remains available. Changing gearsets or their references can make Undo unavailable.
