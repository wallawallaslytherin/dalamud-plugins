# Character Copy

Open `/cc` while logged into the character whose settings you want to copy. Check the source and destinations, then press **Copy to all other characters**. Stay logged in until it finishes.

To copy into one character, open **Import**, select **From** and **Into**, return to the title screen, then press **Import settings** and confirm. Matching destination settings are overwritten.

Use **Undo last copy** on the original source character or at the title screen. Use **Undo last import** at the title screen. Undo covers only the latest transfer.

For full backup recovery, return to the title screen and open **Full backup recovery**, or enter `/cc restore`, then follow the confirmation.
