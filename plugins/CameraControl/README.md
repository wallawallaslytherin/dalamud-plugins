# Cam Control

Open with `/cam` inside a player house. Adjust zoom, field of view, camera height and camera collision. Right-click a numeric control to reset it, or use **Reset all settings**.

Camera changes are restricted to house interiors and stop outside housing, during combat and in duties. Disable other camera-control plugins before use.

Requires Dalamud API 15. Install **Cam Control** through `/xlplugins` after adding this repository's plugin feed.

**WARNING: Use at your own risk!**
