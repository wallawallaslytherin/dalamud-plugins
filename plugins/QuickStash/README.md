# QuickStash
Open your inventory and an FC chest, retainer inventory, or chocobo saddlebag. Hold **Ctrl** and **right-click an item** on either side to move its whole stack to the first empty slot on the other side.
FC chest deposits use the currently open tab. Saddlebag deposits use the selected normal or premium tab. Ordinary right-click keeps the normal item menu. The game applies item restrictions and FC chest permissions.

Use /quickstash to open settings and enable or disable it. If the game rejects an FC chest transfer, check the chest tab permissions.
